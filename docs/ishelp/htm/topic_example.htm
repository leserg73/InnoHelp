Препроцессор Inno Setup: Пример сценария

Пример сценария с именем ISPPExample1.iss располагается в отдельной папке. Выберите в меню «Пуск» ярлык "Inno Setup Example Scripts", созданный при установке Inno Setup, или откройте папку Examples в каталоге установки Inno Setup.

Также смотрите ISPPBuiltins.iss.
