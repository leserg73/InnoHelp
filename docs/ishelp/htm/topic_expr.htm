Препроцессор Inno Setup: #expr, #call

Синтаксис

expr-directive: (expr | call | !) <expr>

Описание

Вычисляет выражение, игнорируя его результат. Эта директива действует как emit, за исключением того, что она не выдаёт ничего на выход препроцессора.

Эта директива предназначена для использования с функциями, которые производят побочные эффекты и не возвращают какого-либо значимого значения.

Пример

#call SaveToFile(AddBackslash(SourcePath) + ("Preprocessed.iss"), \
          Exec(AddBackslash(CompilerPath) + "ISIDE.exe", \
          """" + AddBackslash(SourcePath) + "Preprocessed.iss""")
