Программирование: RaiseLastException

Прототип

procedure RaiseLastException;

Описание

Повторное создание текущего исключения из раздела except. Ничего не делает, если нет текущего исключения.

Пример

begin
  try
    RaiseException('Здесь ваше сообщение');
  except
    Log('Произошло исключение: ' + GetExceptionMessage);
    RaiseLastException;
  end;

  // Следующая строка не будет выполнена, так как исключение было вызвано повторно.
  MsgBox('Это сообщение никто не увидит.', mbInformation, MB_OK);
end;
