Препроцессор Inno Setup: Insert

Прототип функции

void Insert(str *S, int Index, str Substr)

Описание

Выполняет вставку подстроки Substr в строку S в позицию, заданную Index. Строковый параметр S передаётся по ссылке, поэтому модифицируется.

Если значение Index превышает длину строки S, то функция Insert добавит значение подстроки Substr в конец S.

Не связана с insert.

Функция объявлена в файле ISPPBuiltins.iss.
