Командная строка компилятора

  • Другой вариант сборки сценариев — это использовать консольную версию компилятора, файл ISCC.exe. Общий вид использования командной строки следующий:

    iscc [options] <script name>
    Пример:
    iscc "c:\isetup\samples\my script.iss"

    Как показано в примере выше, имена файлов с пробелами должны заключаться в кавычки.

    Чтобы прочитать сценарий из стандартного ввода, укажите - в качестве имени сценария. Подразумевается, что такой сценарий имеет кодировку UTF-8.

    Допустимые параметры:
    ПараметрНазначение
    --output=(yes|no), -o(+|-)Включает или отключает вывод (переопределяет Output).
    --output-dir=<path>, -o<path>Устанавливает путь вывода файла (переопределяет OutputDir).
    --output-filename=<filename>, -f<filename>Устанавливает выходное имя файла (переопределяет OutputBaseFilename).
    --signtool=<name>=<command>, -s<name>=<command>Устанавливает SignTool с указанными именем и командой (инструменты цифровой подписи, настроенные в IDE компилятора, будут добавлены автоматически).
    --no-ide-signtools, -niНе назначать автоматически инструменты подписи, настроенные с помощью IDE компилятора.
    --no-compression, -ncОтключает сжатие (переопределяет Compression и InternalCompressLevel).
    --no-signing, -nsОтключает подписывание (переопределяет SignTool и SignedUninstaller).
    --no-signcheck, -nscОтключает проверку signcheck.
    --messages-jsonl, -mjВыводит ошибки и предупреждения в формате JSONL (предупреждения не подавляются флагом --quiet, если активен флаг --messages-jsonl).
    --preprocess, -eВыводит результат предварительной обработки в стандартный поток вывода (stdout) и подавляет компиляцию.
    --quiet, -qПодавляет сообщения, которые обычно выводятся в стандартный поток вывода (см. --messages-jsonl).
    --quiet-progress, -qpАналогично --quiet, но с отображением хода выполнения.
    --help, -?Выводит информацию об использовании..
    --versionВыводит информацию о версии компилятора.
    Пример:
    iscc --quiet-progress --output-dir="My Output" -f"MyProgram-1.0" -sbyparam=$p "c:\isetup\samples\my script.iss"

    Короткие параметры допускают использование в качестве префикса как -, так и / и нечувствительны к регистру. Длинные опции (с префиксом --) чувствительны к регистру и не допускают использования // в качестве префикса.

    Другие параметры смотрите в разделе "Препроцессор Inno Setup: Компиляция в командной строке".

    ISCC возвращает один из следующих кодов выхода:

    КодЗначение
    0 Компиляция успешна.
    1 Параметры командной строки заданы неверно или произошла внутренняя ошибка.
    2 Компиляция не удалась.

  • Компиляцию сценариев также можно выполнить из командной строки. Общий вид использования командной строки следующий:

    iside -cc <script name>
iside --compile <script name>
    Пример:
    iside -cc "c:\isetup\samples\my script.iss"

    Как показано в примере выше, имена файлов с пробелами должны заключаться в кавычки.

    Короткие параметры допускают использование в качестве префикса как -, так и / и нечувствительны к регистру. Длинные опции (с префиксом --) чувствительны к регистру и не допускают использования // в качестве префикса.

    Запуск компилятора из командной строки не отключает стандартное отображение хода выполнения или сообщения об ошибках.

    IDE компилятора возвращает один из следующих кодов выхода:

    КодЗначение
    0 Компиляция успешна.
    1 Параметры командной строки заданы неверно.
    2 Компиляция не удалась.

  • Мастер создания сценария также может быть запущен из командной строки. Общий вид использования командной строки следующий:

    iside -wizard <wizard name> <script name>
iside --new-script-wizard <wizard name> <script name>
    Пример:
    iside -wizard "MyProg Script Wizard" "c:\temp.iss"

    Обратите внимание, если имена файлов и название мастера содержит пробелы, то они должны заключаться в кавычки.

    Короткие параметры допускают использование в качестве префикса как -, так и / и нечувствительны к регистру. Длинные опции (с префиксом --) чувствительны к регистру и не допускают использования // в качестве префикса.

    Запуск мастера из командной строки не отключает сообщения об ошибках.

    Мастер создания сценария возвращает один из следующих кодов выхода:

    КодЗначение
    0 Какие-либо ошибки отсутствуют и файл сценария успешно сохранён с указанным именем.
    1 Параметры командной строки заданы неверно.
    2 Не удалось сохранить созданный файл сценария.

    Если пользователь отменит работу мастера, будет возвращён код выхода 0, но сценарий не сохранится.
