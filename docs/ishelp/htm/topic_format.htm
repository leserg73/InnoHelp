Препроцессор Inno Setup: Format

Прототип функции

str Format(str Format, ...)

Описание

Форматирует строку Format с использованием последующего ряда аргументов. Форматирование определяется строкой формата Format; результаты возвращаются в виде строки. Каждый аргумент должен быть либо целым числом, либо строкой.

Будет выдана ошибка компилятора, если указана неправильная строка формата, передано слишком мало аргументов или если какие-либо аргументы имеют неправильный тип.

Примечание: в отличие от функции Format в Pascal Scripting, аргументы передаются напрямую, а не в массиве.

Пример

#define AppName "My Program"
#define AppVersion "1.0"
#define OutputBaseFilename Format('%s-%s-setup', AppName, AppVersion)
// OutputBaseFilename = 'My Program-1.0-setup'

#define Count 10
#emit Format('Найдено %d файлов', Count)
// emits 'Найдено 10 файлов'
