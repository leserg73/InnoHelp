Препроцессор Inno Setup: Компиляция в командной строке

Консольная версия компилятора (файл ISCC.exe) автоматически предоставляет дополнительные параметры для управления процессом предварительной обработки сценариев Inno Setup.

Параметр Значение
--define=<name>[=<value>], -d<name>[=<value>] Эмулирует #define public <name> <value> (variable-definition).
-$<letter>(+|-) Эмулирует #pragma option -<letter>(+|-).
-p<letter>(+|-) Эмулирует #pragma parseroption -<letter>(+|-).
--include-dirs=<paths>, -i<paths> Эмулирует #pragma include __INCLUDE__ + ";<paths>" (несколько путей можно разделять точкой с запятой).
--include=<filename>, -j<filename> Эмулирует #include "<filename>".
--inline-start=<string>, -{#<string> Эмулирует #pragma inlinestart <string>.
--inline-end=<string>, -}<string> Эмулирует #pragma inlineend <string>.
--verbose=<number>, -v<number> Эмулирует #pragma verboselevel <number>.

Пример:

iscc -$c- -pu+ "--define=LicenseFile=Trial License.txt" --include-dirs=c:\inc;d:\inc --include=defines.iss "c:\isetup\samples\my script.iss"
