Препроцессор Inno Setup: SetupSetting

Прототип функции

str SetupSetting(str DirectiveName)

Описание

Выполняет синтаксический анализ секции [Setup] в данных текущего вывода препроцессора с целью поиска директивы, заданного параметром DirectiveName. Функция возвращает значение этой директивы, если она найдена, в противном случае — пустую строку.
