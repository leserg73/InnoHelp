Программирование: BrowseForFolder

Прототип

function BrowseForFolder(const Prompt: String; var Directory: String; const Reserved: Boolean): Boolean;

Описание

Отображает диалог, который позволяет пользователю выбрать желаемую папку. Первоначально выбранная папка определяется значением параметра Directory. Возвращает значение True, если пользователь выбрал папку и нажал "OK", в противном случае — False. Выбранная папка возвращается в строковом параметре Directory. В параметре Promt указывается пояснение для пользователя, например, "Выберите папку из списка и нажмите «ОК»", которое будет показано в диалоге.

Параметр Reserved игнорируется, но его всё равно необходимо указывать.
