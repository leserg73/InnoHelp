Программирование: AddPeriod

Прототип

function AddPeriod(const S: String): String;

Описание

Возвращает указанную строку с добавленным символом точка . (U+002E), если только строка не пуста, не оканчивается символом завершения предложения, управляющим символом (например CR или LF) или символом тайского либо лаосского языка (эти языки не завершают предложения точкой), в противном случае строка возвращается без изменений.

Комментарии

Эта функция предназначена в первую очередь для использования при выводе или логировании сообщений об ошибках/исключениях, которые обычно не имеют в конце символа пунктуации.

Поведение данной функции может измениться. Поэтому не следует полагаться на то, что для одной и той же строки результат всегда будет одинаковым. Результат предназначен только для человеческого восприятия и не должен использоваться в виде входных данных для парсеров.
