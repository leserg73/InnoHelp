Препроцессор Inno Setup: ISPPBuiltins.iss

Файл ISPPBuiltins.iss является неотъемлемой частью препроцессора Inno Setup и автоматически устанавливается в корневой каталог Inno Setup. Этот файл автоматически подключается в начале этапа предварительной обработки: некоторые функции ISPP фактически реализованы в нём, а не являются встроенными. Кроме того, файл содержит общие объявления, такие как специальные константы. Поскольку этот файл представляет собой обычный сценарий Inno Setup, вы можете изучить его и использовать содержащиеся в нём приёмы в собственных сценариях.
