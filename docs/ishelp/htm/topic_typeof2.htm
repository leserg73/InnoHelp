Препроцессор Inno Setup: TypeOf2

Прототип функции

int TypeOf2(any Expr)

Описание

Возвращает тип заданного выражения в виде одной из предопределённых констант TYPE_. В отличие от функции TypeOf, которая принимает только идентификатор, эта функция принимает любое выражение, включая элементы массива.

Функция объявлена в файле ISPPBuiltins.iss.
